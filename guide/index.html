Install Claude Code

The orchestrator. One prompt fires the whole pipeline.

Clone the repo

Everything you need is here. No build step.

What's in here?
  • CLAUDE.md — instructions Claude reads automatically
  • .mcp.json — registers the Freebeat MCP server
  • prompts/ — music + video prompt templates
  • tracks.csv — batch input
  • scripts/gen_music.py — KIE Suno helper

Get a KIE API key

KIE is the gateway to Suno (music). Pay-as-you-go, ~$0.10 per track.

  1. Sign up at kie.ai
  2. Top up $5 of credit (more than enough to follow along)
  3. Copy your API key from the dashboard

Run the pipeline

One prompt. Music + video. ~3–5 minutes end to end.

Claude reads CLAUDE.md and runs:

  1. scripts/gen_music.py → KIE Suno → output/demo/music.mp3
  2. freebeat.upload_audio → music_id
  3. freebeat.generate_music_video → task_id
  4. freebeat.get_task_status until done
  5. freebeat.get_task_result → download mp4 to output/demo/video.mp4
Want a custom prompt?

Edit prompts/music.txt and prompts/video.txt — or just describe what you want in chat and Claude will use that instead.
